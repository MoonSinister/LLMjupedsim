## 3. 候选研究假设

- `H1`（主要）：M1 的 ATC 综合分布差异低于 B1、B2 和 A1，且完成率不低于对应基线。
- `H2`（主要）：M1 相对 A1 增加语义区域访问和可解释停留，但不会显著提高 TTL 移除率。
- `H3`（次要）：P1、P2 相对 M1 改变速度、路径长度和区域访问分布，并至少有一个画像扩展降低 ATC 分布差异。
- `H4`（次要）：语义活动与个体画像收益可能伴随旅行时间、拥堵、重路由或计算成本增加。

所有方向性结论必须同时报告估计值、95% 置信区间和效应量；未达到统计证据阈值时不得写成“证明优于”。

## 4. 候选主次指标

- 完成率；
- 旅行时间；
- 路径长度；
- TTL 移除率；
- 真实数据分布差异，包括速度、旅行时间、路径长度、低速比例和区域访问 JSD。

主要指标在 `configs/analysis/statistics.json` 中标记，包括完成率、旅行时间、路径长度、平均速度和 TTL 移除率；真实性主要指标为五个子分布的 JSD 及预注册加权综合分数。

次要/探索性指标包括出口熵、语义区域访问、等待时间、重路由率及额外路径、局部密度、行为状态和 LLM fallback 率。探索性指标不得替代主要指标形成主结论。

## 5. 随机性规则

- 正式方法比较使用完全相同的 seed 列表；
- seed 在正式运行前生成并写入 matrix 配置；
- 仿真、画像抽样和可控的模型采样应分别记录随机源；
- 不得因某个 seed 的结果不利而删除该运行；
- 同一运行内的 agent 不是独立实验重复，跨方法统计以 run/seed 为基本单位。

正式核心矩阵候选 seed 固定为 `2026, 2027, 2028, 2029, 2030`，六种方法共用配对 seed，共 30 个核心运行。seed 来自连续整数预生成规则，不根据结果筛选。

## 6. 运行状态与异常规则

每次运行必须归入以下状态之一：

- `completed`：进程正常退出且关键产物完整；
- `failed`：进程非零退出或关键产物无效；
- `interrupted`：由外部中断，未满足完成条件；
- `planned` / `running`：尚未形成可分析结果。

暂定排除规则：

- manifest 缺失或配置指纹不匹配的运行不进入正式聚合；
- 轨迹数据库损坏、无 agent 或缺少必要表的运行标记为失败；
- LLM 失败后成功 fallback 的运行保留，并统计 fallback；
- 高 TTL 或高重路由本身属于实验结果，不作为排除理由；
- 重试必须保留原失败记录，并产生新的 run 标识。

每个计划项最多按矩阵配置重试；重试仍失败则作为失败样本进入失败敏感性分析。正式主分析使用完整有效运行，补充分析分别按失败视为最差结果和仅可用案例报告，二者差异必须披露。

## 7. 候选统计方案

- 统计单位为独立 `run/seed`，不把 agent 或轨迹帧当作独立重复；
- 描述统计报告 `n`、均值、标准差、中位数、四分位距和确定性 bootstrap 95% CI；
- 配对差值近似正态时使用配对 t 检验并报告配对 Cohen's d，否则使用 Wilcoxon signed-rank 并报告 rank-biserial effect；
- 多场景、多指标推断采用 Holm 校正，校正阈值 `alpha=0.05`；
- 少于 5 个配对运行时输出样本量不足警告，不形成确认性显著结论；
- 综合真实性分数同时报告各子指标，并对权重做预定义敏感性分析。

## 8. 参数搜索与正式评价边界

- `thesis_sensitivity_v1` 仅用于稳健性和参数敏感性，不用于从结果中选择最有利主方法参数；
- pilot 只修复 schema、不可达、系统性 TTL、资源预算等工程问题，不依据效果方向替换 seed；
- 正式矩阵冻结后，scenario、matrix、analysis、plot 和 ATC 参考配置的任何变化都必须创建新版本；
- 正式结果冻结后的新增聚类、指标或权重归入独立探索目录。

## 9. 已知限制

- 当前地图包含多个离散可行走区域，JuPedSim 实际保留最大连通区域；
- 部分人工出口与最终可行走区域仅部分相交；
- ATC 真实轨迹与当前仿真场景不能逐个行人对齐，因此采用分布评价；
- 远程 LLM 服务可能随模型版本和服务参数变化，正式实验必须保存模型、prompt 和响应记录；
- 当前 smoke 在 50 秒上限结束，不能把“轨迹中最后一次出现”无条件解释为正常到达出口；
- 当前已完成统一产物、矩阵、指标、统计、状态、报告和冻结工具；六个主场景 pilot、远程 LLM 正式运行与协议最终冻结仍待执行。
